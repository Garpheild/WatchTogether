# framework

Каркасный слой: константы, обёртки над API платформы, базовые абстракции
(HTTP-клиент, storage, logger), общие для веб-приложения (`src`) и нативных
клиентов (`native`).

Правила:

- без React и без DOM-специфики в публичном API;
- без бизнес-логики — только инфраструктурные примитивы;
- импорт из приложения: `@framework/...`.

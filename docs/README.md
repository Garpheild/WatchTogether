# Watch Party — документация проекта

Watch Party — веб-приложение для совместного просмотра видео с YouTube. Пользователь создаёт
комнату, отправляет ссылку друзьям, и все участники смотрят одно видео синхронно: play, pause и
seek применяются ко всем, рядом работают общий чат и список подключённых участников.

Регистрация не нужна. Доступ к комнате даётся по ссылке и отображаемому имени, а права
разделяются ролями `owner` и `member`.

## Основные возможности MVP

- создание комнаты и вход по уникальной ссылке `/r/{room_code}`;
- ввод отображаемого имени без регистрации;
- одно YouTube-видео на комнату, воспроизводимое через YouTube IFrame Player API;
- синхронизация `play`, `pause`, `seek` между всеми участниками;
- автоматическая выдача актуального состояния новому участнику и после переподключения;
- общий чат с историей;
- список участников с признаком «онлайн»;
- смена видео и закрытие комнаты владельцем;
- лимит 10 участников на комнату.

## Статус

Документация v1.0 от 2026-11-24. Архитектура и контракты зафиксированы, реализация приложения
ещё не начата. Документы в `docs/` — источник истины для API, WebSocket, схемы БД и процессов
команды. Код, расходящийся с документацией, считается ошибкой; изменение контракта начинается с
правки документа и записи в [CHANGELOG_DEV.md](./CHANGELOG_DEV.md).

## Границы документации

Документы описывают только MVP. Всё, что не перечислено в разделе «Возможности», не входит в
текущий объём: аккаунты, пароли на комнату, плейлисты и очередь видео, голосовой чат, модерация,
горизонтальное масштабирование. Эти темы не проектируются заранее, чтобы не усложнять MVP.
